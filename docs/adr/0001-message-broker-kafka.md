# ADR-0001: Брокер сообщений: Apache Kafka (KRaft)

- **Статус:** принято (2026-09-20)
- **Контекст:** PRD (разделы 7 и 13) оставлял выбор между Kafka и Redpanda. Брокер работает на ноутбуке и служит буфером между CDC и Spark (NFR-6).
- **Решение:** Apache Kafka в режиме KRaft (без ZooKeeper).
- **Причины:** Kafka чаще встречается в вакансиях и на собеседованиях; KRaft убирает ZooKeeper и снижает потребление памяти; экосистема (Kafka Connect, Debezium) нативная.
- **Компромиссы:** тяжелее Redpanda по памяти и времени старта; нет встроенной консоли (для просмотра топиков добавить Kafka UI).
- **Последствия:** для отладки используем `kcat` и `kafka-*.sh`; в compose ограничить heap JVM (`KAFKA_HEAP_OPTS`).
