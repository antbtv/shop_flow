# Pi5 network (Wi-Fi)

Ethernet is not available, Pi5 stays on `wlan0`. The address is fixed by a DHCP reservation on the router (MAC of `wlan0` -> `$PI5_HOST`).

NetworkManager profile (generated by netplan on trixie; `nmcli con mod` persists back to netplan):

```bash
CON=$(nmcli -t -f NAME,DEVICE con show --active | grep ':wlan0$' | cut -d: -f1)
sudo nmcli con mod "$CON" 802-11-wireless.cloned-mac-address permanent 802-11-wireless.powersave 2
```

- `cloned-mac-address permanent`: always use the hardware MAC, otherwise the DHCP reservation may not match.
- `powersave 2`: disable Wi-Fi power saving (latency spikes and idle drops on a 24/7 server).

Check: `ip -4 -brief addr show wlan0; /usr/sbin/iw dev wlan0 get power_save`.
